# 工作提報小站

第五週互動網頁作業。延伸自先前工作時依實際需求製作的內部提報網站，重新設計為獨立的課程示範版，移除原公司的識別與資料。

## 使用方式

開啟網站後，可在左下方（手機為頁面上方）切換示範角色：

1. 主管「林予安」：查看多組圖文，選擇答案，檢查並正式送出。
2. 員工「陳小禾」：查看結果、留言、補件，或建立新的提報。
3. 切回主管，確認補件與審核結果。

支援一般提報、多組圖文、圖片及附件、文字與語音留言、草稿保存、搜尋篩選、分享權限、修改紀錄與示範資料重設。

## 實作方式

網站程式與圖像整合於單一 `index.html`，不需要安裝套件或 API 金鑰。資料使用 IndexedDB 保存於目前瀏覽器；不同裝置不會同步。角色切換為示範功能，並非正式帳號驗證。單檔上限 5 MB，語音最長 60 秒。清除網站資料會移除保存的內容。

## 視覺

霧白、鼠尾草綠與淡藍色，搭配卡片、圓角與留白。人物、圖片及工作內容皆為示範資料。

## GitHub Pages

在儲存庫的 Settings → Pages 選擇從 `main` 分支的根目錄部署。
